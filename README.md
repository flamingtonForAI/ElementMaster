# 五行师 · ElementMaster

类 Vampire Survivors 的中式五行割草 Roguelike 网页 Demo。设计文档见 [GDD.md](GDD.md)。

## 运行

```bash
npm install
npm run dev        # http://localhost:5180
npm run build      # 输出到 dist/，纯静态文件
```

## 操作

| 按键 | 作用 |
|---|---|
| 方向键 / WASD | 移动（8 方向）；剑客的剑气斩朝移动方向挥出 |
| ← → + Enter / 空格，或 1 2 3 | 升级时选择 |
| Esc / P | 暂停（暂停菜单里可分别开关音乐、音效） |
| Esc | 选角页回首页；首页的存档页、图鉴页、设置页返回 |
| Q | 选角页进入当前角色的洞府；洞府内 Q / E 切换页签（星图 / 传承 / 修炼），修炼页 T 全部退还；星图页方向键选星位、Enter 点亮、X 撤回、R 重置、+ / − 缩放、拖动平移 |
| R / X | 升级时换签 / 斩缘（洞府里买了才有） |
| `（反引号） | 调试面板（开发模式或地址加 `?debug`） |
| H | 局内开关 HD 光影原型，对比用 |

**手机**：横屏游玩，屏幕空白处按下拖动即出现虚拟摇杆（推得越远走得越快）；点卡片和菜单项选择；顶部 Ⅱ 按钮暂停；竖屏时自动暂停并提示横屏；安卓浏览器在首页右上角、首页设置或暂停菜单里切全屏；iPhone 建议通过“添加到主屏幕”后从桌面图标打开。手机横屏会按屏幕比例扩展视野、铺满画面，菜单与 HUD 避开刘海和底部手势条；人物保持原比例。iPhone 开着静音键时网页没有声音。

## 调试入口

- `?level=1` … `?level=10`：跳过菜单直接进关卡，加 `&char=zhu` / `ruan` / `qingdai` / `moheng` / `xuanyi` 用符师 / 海贼 / 药师 / 傀儡师 / 散人
- HD 光影原型（`src/game/HdLook.ts`，第 1–10 关各一套氛围）：只压暗地砖（上暗下亮 + 暗角），熔岩口、火焰、法术、宝石照亮脚下一小圈地面，瘴雾下的地面泛黄绿；火焰和法术带小光晕和短拖尾，毒雾里飘淡绿雾气；脚下软影子、每关的飘浮物（浮尘、竹叶、雾尘、火星、灰烬、水雾、细雪、风沙、气泡、灵气）、以人物为焦点的上下柔焦、轻微调色。人物和敌人不受光照影响。默认开，局内按 H 切换，地址加 `&hd=0` 关着进
- `?art`：美术预览（主角 8 方向的全部动画、敌人、弹幕、装饰）；`?art=zhu` / `ruan` / `qingdai` / `moheng` / `xuanyi` 看其他角色（同屏还有石傀儡、巨傀）
- `?art=enemies&level=2`：正式怪物逐关预览，方向键左右切关；上排放大 2 倍、下排原尺寸及「凶 / 煞」着色。第 2–10 关已接入原画像素化 PNG，说明见 [素材说明](tools/art/enemies/later-levels-v1/README.md)。
- `/tools/art/enemies/index.html`：开发服务下的第一关怪物造型试稿，对照 AI 原画、当前程序画、24–32px 像素化与密集排列；关卡搭配评审见 [怪物评审](tools/art/enemies/REVIEW.md)。试稿 PNG 未接入战斗；正式敌人和墨衡的召唤物已全部改用原画 PNG（第 2–5 关石俑带地域变体），敌人目前只有移动帧，尚无蓄力/攻击帧。
- 关卡平衡：残兵最多复活一次，火系终结可阻止；瘴雾每半秒伤普通怪 2.5% 最大生命、重叠不叠伤。普通来敌从四周刷新、怪潮完整合围，不预留安全缺口；甩开的怪不再传送回来，绕行空间由清怪和拉扯获得。
- 后期怪物：第 7、9 关的新怪在 30 / 90 秒、第 8 关在 90 / 180 秒分批登场并提示招式，第 10 关按阶段加入进阶怪种。第 6 关起普通厚血前排生命 −15%、经验 +50%，四种快怪生命 +30%、移速 +10%；精英仅继承同类移速修正，前五关与 Boss 不套这项修正。
- 调试面板：无敌、时间倍速、刷怪倍率、升级、跳时间、刷精英/Boss、实时调五行倍率

## 结构

```
src/config/   数值表：五行关系、技能、敌人、关卡、角色（调平衡只改这里）
src/art/      像素美术：程序画 + PNG 原画切片，启动时注册贴图、生成升阶着色
src/audio/    程序化音频：合成器、音效表、BGM 曲谱与播放（随局势叠层）
src/game/     战斗系统：构筑/升级、玩家、敌人（空间网格）、弹幕、拾取、特效、技能、地图
src/scenes/   启动、菜单、游戏、HUD、美术预览
```

技术栈：Phaser 3.90 + TypeScript + Vite；内部分辨率 640×360，整数倍放大；字体为缝合像素字体（OFL，见 `public/fonts/OFL.txt`）。

## 修炼与符箓

- 战斗栏与升级卡使用同一套原生 16px 像素图标：普通术、专属术、心法与五行大招各有独立图形，保留元素色边框与等级；卡片保留名称和效果说明。自带术和大招图标以 2 倍像素尺寸显示，满级标记使用较小的金色 Max。
- 自带术独占左侧大格；初始另有 6 个术与心法**共用**的普通格，合计 7 格。「技能数量」每级增加 1 格，5 级共 12 格：左侧自带术大格、中间两排共 10 个普通小格、右侧大招大格。自带术与 10 项普通术/心法全部满级后自动获得元素大招（金·万剑归宗、木·森罗万象、水·沧海归墟、火·天火焚世、土·昆仑镇岳），玄一按解锁时的本命元素选择。
- 散人开局使用专属「清风拂尘」：无属性扇形扫击并击退，Lv1→8 伤害 18→44、距离 48→68、角度 120°→160°、基础冷却 1.25→1.05 秒。五行伤害倍率一致，不吃地气、本命、周天或克弦加成，不积累元素灵根或异常；仍继承通用增伤、暴击、范围和冷却，敌人护甲正常结算。
- 大招固定 1 级、不可升级，基础冷却 15 秒；凝神诀、角色成长、星图及海贼退射叠加后，连续两次施放最低间隔 10 秒。单次伤害与控制时长随更快的循环下调，大招取消直接回血和护盾，专注攻击与控制。
- 近身范围按命中方式区分：拂尘为较窄的前方扇扫，剑气保留快速斩击与高等级双向波，冰环保留全周控制。离火环轨道半径 48→68、纵向比例 0.8；减冷却加快转速，周回最短 0.35 秒，各火团共享同一目标 0.35 秒命中间隔。
- 远程分工：火球半径 38→58、保留慢速炮击；火球和落石优先覆盖不同敌群。双水龙改为平行通路，合计单龙 150% 伤害；飞叶可靠追踪、完成有限次弹射，飞剑穿透后换目标。玩家直射弹道按经过的路径判定，减少低帧率漏怪。
- 藤缚半径 26→38，重叠区域对同一敌人共享 0.5 秒伤害间隔；通用减冷却最多 75%，剑心和退射仍乘算，大招和离火环各自的下限继续生效。
- 「幸运」共 5 级，每级让符箓出现率、威力、时长和加速幅度相对提高 20%。基础定身/遁符已提升至 6 秒，满幸运 12 秒；符箓刷新率 30% → 60%。爆符以清杂兵为主，精英承受 50% 伤害，Boss 完全免疫。

## 音频

关卡 BGM 已使用文件素材，音效仍由 `src/audio/` 程序化合成：

- BGM：`public/audio/bgm_<曲名>.webm` 优先、同名 MP3 兜底；`src/audio/tracks.ts` 的 `BGM_FILES` 注册后台加载和循环起止点。包含菜单、第 1–10 关、第一关紧张版及 Boss 普通/狂暴版。第 1–10 关的生成方向、来源和循环参数见 [音乐制作记录](tools/audio/README.md)。
- 音效：`this.load.audio('sfx_slash', 'sfx/slash.mp3')`，名字见 `src/audio/sfx.ts`

文件版 BGM 按指定循环点播放，前奏只播一次，主体末尾交叉淡化后回到循环起点；不能叠层，改为随局势开合：强度低时低通压暗（4.5kHz）、音量略收，紧起来全开并推高约 1.7dB；`BGM_FILES` 里标 `calm` 的（菜单曲）不受影响。局势强度主要看同屏数量和贴身的怪，Boss 战从 0.6 起按掉血往上抬。
