# 五行师 · ElementMaster

类 Vampire Survivors 的中式五行割草 Roguelike 网页 Demo。设计文档见 [GDD.md](GDD.md)。

## 运行

```bash
npm install
npm run dev        # http://localhost:5180
npm run build      # 输出到 dist/，纯静态文件
```

## 操作

| 按键 | 作用 |
|---|---|
| 方向键 / WASD | 移动（8 方向）；剑客的剑气斩朝移动方向挥出 |
| ← → + Enter / 空格，或 1 2 3 | 升级时选择 |
| Esc / P | 暂停（暂停菜单里可分别开关音乐、音效） |
| M | 标题页开关声音 |
| `（反引号） | 调试面板（开发模式或地址加 `?debug`） |

**手机**：横屏游玩，屏幕空白处按下拖动即出现虚拟摇杆（推得越远走得越快）；点卡片和菜单项选择；顶部 Ⅱ 按钮暂停；竖屏时自动暂停并提示横屏；安卓浏览器在标题页右上角或暂停菜单里切全屏；iPhone Safari 不支持网页全屏，用“添加到主屏幕”后从桌面图标打开即为全屏。iPhone 开着静音键时网页没有声音。

## 调试入口

- `?level=1`、`?level=2`：跳过菜单直接进关卡
- `?art`：美术预览（主角 8 方向的全部动画、敌人、弹幕、装饰）
- 调试面板：无敌、时间倍速、刷怪倍率、升级、跳时间、刷精英/Boss、实时调五行倍率

## 结构

```
src/config/   数值表：五行关系、技能、敌人、关卡、角色（调平衡只改这里）
src/art/      程序化像素美术（逐像素绘制 + 自动描边），启动时生成贴图
src/audio/    程序化音频：合成器、音效表、BGM 曲谱与播放（随局势叠层）
src/game/     战斗系统：构筑/升级、玩家、敌人（空间网格）、弹幕、拾取、特效、技能、地图
src/scenes/   启动、菜单、游戏、HUD、美术预览
```

技术栈：Phaser 3.90 + TypeScript + Vite；内部分辨率 640×360，整数倍放大；字体为缝合像素字体（OFL，见 `public/fonts/OFL.txt`）。

## 音频

音效和 BGM 目前全部程序化合成（`src/audio/`），没有音频文件。之后换成正式素材时，在 `BootScene` 里用同名 key 加载即可覆盖，调用方不用改：

- BGM：`this.load.audio('bgm_level1', 'music/level1.mp3')`，曲名见 `src/audio/tracks.ts`（`menu`、`level1`、`level2`、`boss`）
- 音效：`this.load.audio('sfx_slash', 'sfx/slash.mp3')`，名字见 `src/audio/sfx.ts`

文件版 BGM 整首循环播放，不会随局势叠层。
